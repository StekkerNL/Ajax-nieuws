AJAX NIEUWS VOOR ANDROID

Dit is een Android Studio-project. Het ZIP-bestand is GEEN installeerbare APK.

Zo maak je zelf een APK:
1. Installeer Android Studio op Windows, macOS of Linux.
2. Pak de ZIP uit en open de map AjaxNieuws_Android in Android Studio.
3. Laat Android Studio de benodigde Android SDK en Gradle ophalen.
4. Kies Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Zet de APK op je Android telefoon en installeer hem.

Functies:
- Nederlandstalige Ajax headlines via Google Nieuws RSS.
- Tweede zoekopdracht voor Ajax transfers.
- Nieuws overzicht met bron, tijdstip, categorisering en artikellink.
- Opslag van maximaal 200 nieuwsitems, eenvoudige deduplicatie.
- Achtergrondcontrole via Android JobScheduler op een interval van minstens 15 minuten.
- Notificatie bij gevonden nieuwe berichten (na eerste import), mits toegestaan.

Belangrijk: Android kan achtergrondtaken uitstellen door batterijbesparing.
Dit is een prototype en is niet getest op een fysieke telefoon of via een volledige APK-build.
Google Nieuws RSS werkt op basis van openbare RSS-search feeds en kan veranderen.
De artikelen blijven van hun respectievelijke uitgevers. De app toont koppen en links.
